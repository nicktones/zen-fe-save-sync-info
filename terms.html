Save-sync terms of use

Effective 4 October 2026. These terms cover the Google Drive save-sync feature maintained by the Zen-FE project.

Using the feature

Use save sync only with Google accounts, devices and save files you are authorised to access. You choose which Eden user folder is linked and whether automatic sync is enabled. Use the same Google account and recovery code on linked devices.

Recovery and availability

Keep independent backups of progress you want to retain and keep your recovery code private. Sync depends on device permissions, network availability, Google authorization and compatible save files. Conflicts require you to choose a revision. A lost recovery code can prevent access to encrypted cloud saves.
